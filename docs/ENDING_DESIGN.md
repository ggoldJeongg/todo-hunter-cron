# 주간 엔딩 시스템 설계

## 1. 개요

매주 일요일 자정, 캐릭터의 주간 스탯(STR/INT/EMO/FIN/LIV) 조합을 분석하여 엔딩을 결정한다.
프린세스 메이커 방식으로, 가장 높은 스탯 1~2개의 조합에 따라 엔딩이 분기된다.

## 2. 엔딩 판정 흐름

```
매주 일요일 자정 (EndingOpen 크론)
  1. endingState=1 (DISABLED) 인 캐릭터 조회
  2. 각 캐릭터의 Status(STR/INT/EMO/FIN/LIV) 조회
  3. 스탯 조합 분석 → 엔딩 ID 결정
  4. 캐릭터에 endingId 저장 + endingState=2 (ENABLED)
  5. 클라이언트에서 엔딩 컷신 표시

매주 월요일 자정 (EndingClose + StatusReset 크론)
  1. 전체 캐릭터 endingState=1 (DISABLED)
  2. 전체 Status 스탯 0으로 초기화
```

## 3. 엔딩 판정 로직

### 3.1 판정 우선순위

```
1순위: 특수 엔딩 (올스탯 조건)
2순위: 듀얼 스탯 엔딩 (상위 2개 스탯이 비슷할 때)
3순위: 단일 스탯 엔딩 (1개 스탯이 압도적일 때)
4순위: 기본 엔딩 (스탯이 너무 낮을 때)
```

### 3.2 판정 기준

```typescript
// 스탯 배열로 변환
const stats = { str, int, emo, fin, liv };
const sorted = Object.entries(stats).sort((a, b) => b[1] - a[1]);

const [first, second] = sorted;       // 1위, 2위 스탯
const total = str + int + emo + fin + liv;
const max = first[1];
const min = Math.min(str, int, emo, fin, liv);
const gap = first[1] - second[1];     // 1위와 2위의 차이

// 1순위: 특수 엔딩
if (total === 0)                        → "나태한 모험가" (배드 엔딩)
if (total >= 50 && max - min <= 2)      → "전설의 영웅" (트루 엔딩)
if (max - min <= 2 && total >= 10)      → "진정한 용사" (히든 엔딩)

// 2순위: 듀얼 스탯 (1위와 2위 차이가 2 이하)
if (gap <= 2 && first[1] >= 3)         → 듀얼 조합 엔딩

// 3순위: 단일 스탯 (1위가 압도적)
if (first[1] >= 3)                      → 단일 스탯 엔딩

// 4순위: 기본
else                                    → "평범한 하루" (기본 엔딩)
```

## 4. 엔딩 목록

### 4.1 특수 엔딩 (3개)

| ID | 코드 | 엔딩 이름 | 조건 | 배경 |
|----|------|-----------|------|------|
| S1 | `LAZY_ADVENTURER` | 나태한 모험가 | 올스탯 합계 = 0 | bg_lazy |
| S2 | `TRUE_HERO` | 진정한 용사 | 올스탯 균형 (편차 ≤ 2, 합계 ≥ 10) | bg_hero |
| S3 | `LEGENDARY` | 전설의 영웅 | 올스탯 균형 (편차 ≤ 2, 합계 ≥ 50) | bg_legendary |

#### 스토리

**S1 - 나태한 모험가**
> 여관 침대에서 뒹굴며 한 주가 지나갔다.
> 창밖으로 들려오는 모험가들의 발소리가 점점 멀어진다.
> "내일부터 시작하지 뭐..." 라고 중얼거리며 다시 눈을 감는다.

**S2 - 진정한 용사**
> 검술도, 마법도, 마음도, 살림도 모두 갈고닦은 한 주.
> 마을 사람들이 말한다. "저 사람이야말로 진정한 용사다."
> 어떤 위기가 와도 흔들리지 않는, 균형 잡힌 영웅의 모습이 빛난다.

**S3 - 전설의 영웅**
> 모든 분야에서 극에 달한 능력치. 세계가 당신의 이름을 기억한다.
> 전설은 이렇게 기록된다 — "그는 모든 것을 해냈다."
> 왕국의 기사도, 마법학원의 현자도, 모두가 당신을 우러러본다.

### 4.2 단일 스탯 엔딩 (5개)

| ID | 코드 | 최고 스탯 | 엔딩 이름 | 배경 |
|----|------|-----------|-----------|------|
| A1 | `STEEL_WARRIOR` | STR | 강철의 전사 | bg_battle |
| A2 | `SAGE_PATH` | INT | 현자의 길 | bg_library |
| A3 | `EMPATHY_POET` | EMO | 공감의 시인 | bg_forest |
| A4 | `GOLDEN_MERCHANT` | FIN | 황금의 상인 | bg_market |
| A5 | `VILLAGE_GUARDIAN` | LIV | 마을의 수호자 | bg_village |

#### 스토리

**A1 - 강철의 전사 (STR)**
> 쉬지 않고 몸을 단련한 한 주. 근육에 힘이 넘친다.
> 마을을 위협하던 몬스터를 압도적인 힘으로 제압했다.
> 사람들이 환호한다. "강철의 전사 만세!"

**A2 - 현자의 길 (INT)**
> 지식을 갈구하며 책과 함께한 한 주.
> 고대 마법서를 해독해 몬스터의 약점을 간파했다.
> 힘이 아닌 지혜로 거둔 승리. 마법학원에서 초청장이 왔다.

**A3 - 공감의 시인 (EMO)**
> 마음을 열고 세상과 교감한 한 주.
> 몬스터와 대화에 성공했다. 알고 보니 외로운 존재였다.
> 칼 대신 말로 해결한 이야기가 마을에 퍼진다.

**A4 - 황금의 상인 (FIN)**
> 재화를 모으고 투자한 한 주. 금화가 쌓여간다.
> 용병을 고용해 몬스터를 처리하고, 마을 경제를 부흥시켰다.
> "돈이면 안 되는 게 없지." 자신만만한 미소를 짓는다.

**A5 - 마을의 수호자 (LIV)**
> 마을 곳곳을 정비하며 보낸 한 주.
> 성벽을 보강하고 함정을 설치해 몬스터가 접근조차 못 한다.
> 마을 사람들이 평화로운 밤을 보낸다. 모두 당신 덕분이다.

### 4.3 듀얼 스탯 엔딩 (10개)

| ID | 코드 | 조합 | 엔딩 이름 | 배경 |
|----|------|------|-----------|------|
| D1 | `MAGIC_SWORDSMAN` | STR + INT | 마검사 | bg_battle |
| D2 | `GUARDIAN_KNIGHT` | STR + EMO | 수호기사 | bg_battle |
| D3 | `ARENA_CHAMPION` | STR + FIN | 투기장의 챔피언 | bg_battle |
| D4 | `WILD_HUNTER` | STR + LIV | 자급자족 사냥꾼 | bg_forest |
| D5 | `HEALING_MAGE` | INT + EMO | 치유의 마법사 | bg_library |
| D6 | `ALCHEMIST` | INT + FIN | 연금술사 | bg_library |
| D7 | `INVENTOR` | INT + LIV | 발명가 | bg_village |
| D8 | `BARD` | EMO + FIN | 음유시인 | bg_market |
| D9 | `DRUID` | EMO + LIV | 드루이드 | bg_forest |
| D10 | `GUILD_MASTER` | FIN + LIV | 길드 마스터 | bg_market |

#### 스토리

**D1 - 마검사 (STR + INT)**
> 검과 마법, 두 가지 길을 동시에 걸은 한 주.
> 전략적 전투로 보스급 몬스터를 단독 격파했다.
> 마법 검사의 전설이 시작된다.

**D2 - 수호기사 (STR + EMO)**
> 힘을 기르되, 지키고 싶은 사람을 떠올린 한 주.
> 동료가 위험에 빠졌을 때 몸을 던져 막아냈다.
> "당신이 있어서 든든합니다." 동료의 눈에 눈물이 맺힌다.

**D3 - 투기장의 챔피언 (STR + FIN)**
> 전투력을 갈고닦으며 상금을 노린 한 주.
> 투기장에서 연전연승. 명성과 부를 동시에 거머쥐었다.
> 관중의 환호 속에서 챔피언 벨트를 들어올린다.

**D4 - 자급자족 사냥꾼 (STR + LIV)**
> 숲에서 몸을 단련하며 자연과 함께한 한 주.
> 몬스터를 사냥하고, 직접 요리하고, 자유롭게 살아간다.
> 누구에게도 얽매이지 않는 사냥꾼의 삶.

**D5 - 치유의 마법사 (INT + EMO)**
> 지식과 공감 능력을 함께 키운 한 주.
> 치유 마법을 개발해 몬스터에게 상처받은 마을 사람을 치료했다.
> "고마워요, 선생님." 아이의 미소가 보답이다.

**D6 - 연금술사 (INT + FIN)**
> 지식을 돈으로 바꾸는 법을 터득한 한 주.
> 몬스터 재료로 묘약을 제조해 대박 사업을 벌였다.
> 실험실과 금고가 동시에 가득 찬다.

**D7 - 발명가 (INT + LIV)**
> 머리를 쓰며 생활을 개선한 한 주.
> 마법 도구를 발명해 마을의 생활 수준을 한 단계 끌어올렸다.
> "이 세상을 더 편리하게!" 오늘도 설계도를 그린다.

**D8 - 음유시인 (EMO + FIN)**
> 감성과 사업 감각을 동시에 발휘한 한 주.
> 모험담을 노래로 만들어 전국을 순회한다.
> 감동과 금화를 동시에 거두는 예술가의 삶.

**D9 - 드루이드 (EMO + LIV)**
> 자연과 마음으로 교감한 한 주.
> 숲의 정령과 친구가 되어 자연의 균형을 지킨다.
> 바람이 속삭인다. "숲이 당신을 기억합니다."

**D10 - 길드 마스터 (FIN + LIV)**
> 재정과 실무를 동시에 챙긴 한 주.
> 모험가 길드를 설립하고 체계적으로 마을을 운영한다.
> 모든 모험가가 당신의 길드 문을 두드린다.

## 6. 데이터 구조

### 6.1 엔딩 데이터 타입

```typescript
type EndingType = "special" | "single" | "dual" | "default";

interface EndingData {
  id: string;           // "S1", "A1", "D1", "F1"
  code: string;         // "STEEL_WARRIOR"
  name: string;         // "강철의 전사"
  type: EndingType;
  stats?: string[];     // ["str"] 또는 ["str", "int"]
  story: string[];      // 스토리 텍스트 (줄 단위 배열)
  background: string;   // "bg_battle"
}
```

### 6.2 판정 결과 타입

```typescript
interface EndingResult {
  characterId: number;
  endingId: string;     // "A1", "D5", "S2" 등
  stats: {
    str: number;
    int: number;
    emo: number;
    fin: number;
    liv: number;
  };
  determinedAt: Date;
}
```

## 7. 엔딩 상태 (EndingState)

| 값 | 상태 | 설명 |
|----|------|------|
| 0 | PENDING | 초기 상태 (캐릭터 생성 직후) |
| 1 | DISABLED | 엔딩 비활성 (월~토) |
| 2 | ENABLED | 엔딩 확인 가능 (일요일) |
| 3 | CHECKED | 엔딩 확인 완료 |
